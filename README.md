# 🌾 AI Integrated Agricultural Advisor

An AI-powered agricultural advisory system designed to help farmers make better farming decisions using soil, weather, and crop data.

## 🚀 Features

- Crop Recommendation based on soil nutrients
- Weather-based farming suggestions
- Soil Health Analysis
- User-friendly dashboard
- AI-powered decision support
- Telugu language support

## 🛠️ Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Supabase

### AI / Data
- Machine Learning
- Agricultural Dataset Analysis

## 🎯 Problem Statement

Farmers often face challenges in selecting suitable crops and managing resources efficiently.

This project provides intelligent recommendations based on available agricultural data, helping farmers improve productivity and make informed decisions.
